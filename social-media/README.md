## 危机处理

### 假冒账号处理
1. 立即截图保存证据
2. 向平台举报假冒账号
3. 发布警告声明
4. 提醒粉丝注意甄别

### 负面评论处理
1. 先私下了解具体情况
2. 公开回复表示重视
3. 提供解决方案

1. 第一时间发布安全提示

3. 持续更新进展
4. 事后总结报告
