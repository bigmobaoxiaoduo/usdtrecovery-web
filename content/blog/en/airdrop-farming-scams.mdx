## Identification and Prevention

### Red Flags 🚩

Stop immediately if you encounter:

- [ ] Requests for private keys or seed phrases
- [ ] Promises of "guaranteed" high returns
- [ ] Urgent demands for immediate transfer
- [ ] Contact through unofficial channels
- [ ] Subtle spelling errors in domain names

### Security Best Practices

1. **Always verify** - Verify through official channels before any operation
2. **Use hardware wallets** - Store large amounts in hardware wallets
3. **Enable 2FA** - Use two-factor authentication, but avoid SMS verification
4. **Check URLs carefully** - Inspect URLs carefully, use bookmarks

## If You've Become a Victim

### Immediate Action Checklist

1. **Stop the loss** - Disconnect from network to prevent further damage
2. **Save evidence** - Screenshot and save all relevant records
3. **Contact exchange** - If funds entered an exchange, request freeze immediately
4. **Report to police** - Gather evidence and report to local authorities
